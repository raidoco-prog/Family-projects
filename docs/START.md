## חלק א — אני רק רוצה להשתמש

**לא צריך להתקין שום דבר מחנות האפליקציות.** זה אתר, ומוסיפים אותו למסך
הבית כך שייראה ויתנהג כמו אפליקציה.

מה שצריך: הקישור לאפליקציה (מי שהקים אותה שלח לכם אותו) וחשבון גוגל, או
כתובת מייל.

### באייפון ובאייפד

1. פתחו את הקישור **ב-Safari**. חשוב שזה יהיה ספארי ולא כרום.
2. התחברו עם גוגל, או בקשו קישור כניסה למייל.
3. לחצו על כפתור **השיתוף** — הריבוע עם החץ למעלה, בתחתית המסך.
4. גללו ובחרו **«הוספה למסך הבית»**, ואז «הוסף».
5. סגרו את ספארי ופתחו את האפליקציה **מהסמל החדש** שנוסף למסך.
6. בתוך האפליקציה: **הגדרות** (סמל הפעמון למעלה) → **הפעלת התראות** →
   אשרו כשהאייפון שואל.

> **בלי שלבים 3–6 לא תקבלו אף התראה.** באייפון, התראות עובדות רק כשהאתר
> נפתח מהסמל שבמסך הבית — זו מגבלה של אפל ולא הגדרה שאפשר לשנות. מסך
> ההגדרות מזהה את המצב ומראה בדיוק מה חסר.

### באנדרואיד

1. פתחו את הקישור ב-**Chrome**.
2. התחברו.
3. בתפריט (שלוש נקודות למעלה) בחרו **«התקנת האפליקציה»** או
   **«הוספה למסך הבית»**.
4. פתחו מהסמל החדש → **הגדרות** → **הפעלת התראות**.

### במחשב

פשוט פתחו את הקישור בדפדפן והתחברו. אפשר לסמן את הדף במועדפים.
התראות במחשב עובדות בכרום ובאדג׳, אבל האפליקציה בנויה קודם כול לטלפון.

### בדיקה שהכול עובד

- אתם רואים את שמות כל בני המשפחה למעלה.
- ב**קניות**, הוספת פריט מופיעה מיד גם בטלפון של מישהו אחר.
- ב**הגדרות** כתוב «התראות פעילות» ולא «צריך להוסיף למסך הבית».

### שאלות שחוזרות

**קיבלתי קישור הזמנה — מה עושים איתו?** פותחים אותו בטלפון ומתחברים.
הקישור תופס אתכם לשורה שכבר קיימת במערכת, כך שכל מה ששייך לכם כבר שם.
הוא תקף שבועיים ועובד פעם אחת בלבד.

**אין לי קליטה בסופר.** רשימת הקניות עובדת בכל מקרה — היא נשמרת בטלפון,
ומה שסימנתם או הוספתם נשלח לבד ברגע שהקליטה חוזרת. יופיע פס שאומר
«אין קליטה». שאר המסכים דורשים חיבור.

**האפליקציה לא נפתחת / מסך לבן.** סגרו ופתחו מחדש מהסמל. אם זה נמשך,
פתחו את הקישור בדפדפן רגיל — ככה תדעו אם הבעיה באפליקציה או ברשת.

**לא מגיעות התראות.** כמעט תמיד הסיבה היא שהאפליקציה נפתחה מספארי ולא
מהסמל במסך הבית. היכנסו להגדרות שבאפליקציה — אם כתוב שם «צריך להוסיף
למסך הבית», זו הסיבה.

## חלק ב — הקמה על המחשב

זה נדרש **פעם אחת**, למי שמעלה את המערכת לאוויר או משנה בה קוד.
בני המשפחה לא צריכים את זה.

### 1. מה מתקינים

| מה | בשביל מה | מאיפה |
|---|---|---|
| **Node.js** גרסה 20 ומעלה | מריץ את האפליקציה | [nodejs.org](https://nodejs.org) — הורידו את «LTS» |
| **Git** | מוריד את הקוד ושומר שינויים | [git-scm.com](https://git-scm.com) |
| עורך קוד (מומלץ **VS Code**) | לערוך קבצים | [code.visualstudio.com](https://code.visualstudio.com) |

בשני הראשונים לוחצים «הבא» עד הסוף — אין מה להגדיר.

בנוסף צריך שני חשבונות, שניהם בחינם ושניהם נפתחים עם גוגל:
**[Supabase](https://supabase.com)** (מאחסן את הנתונים) ו-
**[Vercel](https://vercel.com)** (מאחסן את האתר).

### 2. בדיקה שההתקנה הצליחה

פתחו **Terminal** (במק) או **PowerShell** (בווינדוס) והדביקו:

```bash
node -v
git --version
```

צריך לקבל מספר גרסה בכל שורה, למשל `v22.14.0`. אם כתוב
«command not found» — ההתקנה לא הושלמה, או שצריך לסגור ולפתוח את החלון
מחדש.

### 3. הורדת הקוד

```bash
git clone https://github.com/raidoco-prog/Family-projects.git
cd Family-projects/web
npm install
```

`npm install` לוקח דקה או שתיים ומוריד את הספריות. אזהרות בצהוב הן בסדר;
מה שחשוב זה שלא תהיה שגיאה אדומה בסוף.

### 4. חיבור למסד הנתונים

בלי השלב הזה האפליקציה עולה ומציגה מסך בשם **«חסרים פרטי החיבור ל-Supabase»**
שמסביר מה חסר, במקום ליפול בשגיאה. זה תקין — ככה אמור להיראות המצב לפני
שמילאתם את הפרטים.

1. ב-Supabase פתחו פרויקט חדש באזור `eu-central-1`.
2. **SQL Editor** → הדביקו את כל התוכן של
   [`docs/schema.sql`](./schema.sql) → **Run**.
3. **Authentication → Providers** → הפעילו **Google** ו-**Email**.
4. העתיקו את המפתחות:

```bash
cp .env.example .env.local
```

פתחו את `.env.local` בעורך ומלאו מ-**Settings → API** ב-Supabase.
[`DEPLOYMENT.md`](./DEPLOYMENT.md) מסביר מה כל משתנה עושה ומה נשבר בלעדיו.

### 5. הרצה

```bash
npm run dev
```

פתחו בדפדפן: **http://localhost:3000**

לעצירה: `Ctrl+C` בחלון הטרמינל.

### לבדוק מהטלפון בזמן פיתוח

בהרצה, Next מדפיס שתי כתובות — `Local` ו-`Network`. השנייה נראית כמו
`http://192.168.1.20:3000`. אם הטלפון מחובר לאותו Wi-Fi, אפשר לפתוח
אותה ממנו.

**אבל:** «הוספה למסך הבית» והתראות **לא יעבדו** ככה, כי הן דורשות
HTTPS. את זה בודקים רק אחרי העלאה לאוויר, שם הכתובת מאובטחת ממילא.

### פקודות שימושיות

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | מריץ לפיתוח, מתעדכן עם כל שמירה |
| `npm run build` | בונה לפרודקשן ובודק טיפוסים |
| `npm run lint` | בודק את הקוד |
| `npm start` | מריץ את מה שנבנה |

### 6. העלאה לאוויר

זה מה שנותן לכם כתובת אמיתית לשלוח למשפחה, וזה מה שמאפשר התראות.
התהליך המלא ב-[`DEPLOYMENT.md`](./DEPLOYMENT.md), כולל את המשתנה
שהכי קל לשכוח — בלעדיו האתר עולה ונראה תקין, ואף אחד לא מצליח להתחבר.

## תקלות נפוצות בהקמה

| מה רואים | מה זה אומר |
|---|---|
| `command not found: node` | Node לא מותקן, או שצריך לסגור ולפתוח את הטרמינל |
| «Port 3000 is in use» | כבר רץ משהו על 3000. Next יבחר פורט פנוי לבד ויכתוב איזה — פשוט פתחו את הכתובת שהוא הדפיס |
| מסך «חסרים פרטי החיבור ל-Supabase» | `.env.local` ריק או חסר. חזרו לשלב 4 |
| הדף נטען אבל אין נתונים | `schema.sql` לא רץ ב-Supabase |
| `npm install` נכשל | בדקו ש-Node הוא 20 ומעלה עם `node -v` |
